# Models API Reference

## EvalInput

The input data for evaluation.

```python
from fasteval import EvalInput

eval_input = EvalInput(
    actual_output="The response text",
    expected_output="Expected text",
    input="User query",
    context="Additional context",
    history=[
        {"role": "user", "content": "Hi"},
        {"role": "assistant", "content": "Hello!"}
    ]
)
```

### Fields

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| actual_output | str | Yes | The output to evaluate |
| expected_output | str | No | Reference output |
| input | str | No | Input query |
| context | str | No | Additional context |
| history | List[Dict] | No | Conversation history |

## EvalResult

Returned after evaluation. `passed` is `True` only if all metrics passed.

```python
result.passed  # bool
result.metric_results  # List[MetricResult]
```

## MetricResult

Result from a single metric evaluation.

```python
metric_result.metric_name  # str
metric_result.score  # float
metric_result.passed  # bool
metric_result.threshold  # float
metric_result.reasoning  # str
metric_result.details  # dict: metric-specific details
```

For LLM-judged metrics, `details["judge_calls"]` lists every call made to the judge, one entry per attempt:

```python
{
    "judge": {"provider": "OpenAIClient", "model": "gpt-4o-mini", "temperature": 0.0},
    "messages": [{"role": "user", "content": "..."}],  # the prompt sent
    "response": "{\"score\": 0.9, \"reasoning\": \"...\"}",  # raw response, if the call returned
    "error": "TimeoutError: ...",  # only if the call raised
    "latency_ms": 812.4,
}
```

Long text is truncated to 20,000 characters and image or audio content is omitted. Metrics scored by a [prompt judge](/docs/cli/prompt-judges) (directly or through a `--judge` swap) also have `details["prompt_judge"]` with the judge's `name` and `based_on`.

## MetricConfig

Configures a metric for use with the Evaluator API.

```python
from fasteval import MetricConfig

config = MetricConfig(
    metric_type="correctness",
    name="correctness",
    threshold=0.7
)
```
